# Matrix New Tab

A Chrome extension that replaces the new tab page with an animated Matrix code rain background and customizable app shortcuts.

## Features

- **Matrix Code Rain** — Katakana + Latin characters falling in columns with glowing trails
- **Highlight columns** — ~12% of columns are extra bright for depth
- **Phosphor glow** — optional CRT-style green glow on characters
- **Multi-page app grid** — 2 rows × 6 columns per page, 3 pages
- **Scroll navigation** — scroll, arrow keys, or swipe to switch pages
- **Quick search** — start typing to open Google search
- **Settings** — tile size, rain speed (slow/normal/fast), glow on/off

## Install

1. Clone or download this repo
2. Go to `chrome://extensions`
3. Enable **Developer mode**
4. Click **Load unpacked** → select this folder
